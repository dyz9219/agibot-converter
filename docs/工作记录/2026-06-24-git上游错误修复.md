# 2026-06-24 Git 上游错误修复

## 问题背景

仓库出现大量 `Isaac Downloader` 相关文件，包含 `app.go`、`main.go`、`go.mod`、`frontend/`、`backend/downloader.go`、`go1.23.6*.tar.gz` 等。这些文件不属于当前 `agibot-converter` Python 转换器项目。

## 根因分析

当前仓库曾同时配置两个远端：

- `origin`: `https://github.com/dyz9219/agibot-converter.git`
- `gitlab`: `http://172.16.40.101:8888/isaac-sim/downloader.git`

更关键的是，`branch.main.remote` 被错误配置为 downloader 仓库 URL：

```text
branch.main.remote http://dengyangzhi:***@172.16.40.101:8888/isaac-sim/downloader.git
branch.main.merge refs/heads/main
```

因此在当前转换器仓库执行普通 `git pull` 时，Git 拉取并尝试合并的是 `isaac-sim/downloader.git` 的 `main` 分支，而不是 `agibot-converter` 的 `origin/main`，从而产生跨项目合并冲突和大量 downloader 文件。

## 改动方案

- 将 `main` 分支上游改回 `origin/main`；
- 删除错误的 `gitlab` 远端，避免后续误拉 downloader 仓库；
- 执行 `git merge --abort` 中止错误合并；
- 删除错误合入后残留的 downloader 未跟踪文件。

## 量化结果

- 修正分支上游：1 个，`main -> origin/main`
- 删除错误远端：1 个，`gitlab`
- 中止错误 merge：1 次
- 清理 downloader 残留文件/目录：27 项

## 验证方式

- `git config --get-regexp "^remote\\..*\\.(url|fetch)$|^branch\\.main\\.(remote|merge)$"`
- `Test-Path .git\\MERGE_HEAD`
- `git status --short --branch --ignored`

## 当前结论

当前 `main` 已恢复跟踪 `origin/main`，错误 merge 已结束，`Isaac Downloader` 文件已从工作区清理。工作区只剩本地忽略项，例如 `.venv/`、`.idea/`、`.worktrees/` 以及当前 `.gitignore` 忽略的部分 `test/python/test_*.py`。

## 下一步建议

后续在该仓库中执行拉取时，使用 `git pull origin main` 或确认 `git status --branch` 显示 `main...origin/main`。不要在同一仓库中保留无关项目远端，尤其不要把当前分支上游配置到其他项目仓库。
